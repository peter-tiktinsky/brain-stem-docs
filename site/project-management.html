Project management

This section covers the operational side of getting work done: how you organize a project, shape an idea into a plan, run that plan under safe human gates, and keep a single up-to-date view of every project's research and decisions. Each page covers one layer of that stack.

Process governance lives here. Write-time conventions (how individual files are shaped and governed at the moment they are created) live in Write-time governance.

What Claude Code gives you — and what's missing

Natively, Claude Code persists plans and tasks across sessions and can coordinate parallel agents. What those primitives don't form is a durable lifecycle from raw idea through research, decision, execution, verification and reuse — without one control model, duplicate ideas survive, evidence separates from the work, and status drifts from what's actually on disk.

Claude Code gives youWhat's missingbrain-stem adds
Plans and tasks that persist across sessionsDuplicate ideas survive and status becomes a claim rather than something checked against artifactsAn inbox-to-plan pipeline with an executable control file and independent verification (plans) (brain-stem specific)
Parallel-work primitives, including experimental agent teamsDirect teammate messaging leaves agent reporting outside the durable plan recordHuman-gated orchestration that routes agent work back through the plan (built on native)
Session transcripts the platform can resumeA resumed transcript carries the conversation, not the project's semantic stateA generated project binder with an append-only handoff journal (brain-stem specific)

Two kinds of governance — and where each lives

brain-stem splits its governance concerns into two categories so they stay separate and legible.

This section

Process governance

How work is organized and tracked over time: where project work lives, how plans are made and progressed, how execution is orchestrated safely, and how a project's knowledge rolls up into one view. The rules here are about workflow — how a multi-step effort moves from idea to done.

Write-time governance section

Write-time governance

How each file is shaped the moment it is created: the frontmatter it requires, the folder it belongs in, the naming it must follow. These rules fire on every Edit and Write to keep files discoverable by Claude and findable by you, with a librarian sweep as the backstop for files written by other means — independent of any particular plan or project.
